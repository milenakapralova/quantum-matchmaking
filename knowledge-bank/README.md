# EQTA knowledge bank

A structured reading of *Exploratory Quantum Technology Assessment* (EQTA), English edition, © 2023 Quantum Delta Nederland. The bank restates the document so later work can use its ideas, questions, examples, and limits without re-reading the PDF.

This bank does not update the document. Laws, standards, and qubit roadmaps have moved since 2023. Where the text forecasts a law or dates a milestone, that forecast is recorded as the document’s 2023 position.

Booklet page *P* is PDF page *P + 3*. A running head such as `02 03` marks a two-page spread. The table of contents uses booklet pages. Citations in this bank use those booklet pages.

`source/eqta-full-extract.txt` is a plain-text extraction. Running headers sometimes repeat letters, and some footnotes lose spaces. Prefer this bank for reading, and the PDF when a sentence must be checked.

The separate file `EQTA-working-doc-QDNL-2026.pdf` is not part of this bank.

## Status of the tool

The EQTA is a voluntary roadmap. The document expects that a future European regime might use binding assessments, certification, and lifecycle audits. That is a forecast, not the status of this edition.

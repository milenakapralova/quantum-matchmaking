# User-friendly design asks

These are the design requests from the conversation about the Solutions Forward Challenges matchmaking tool. They are grouped by what each one was trying to make easier at the event. Under each request is the principle behind it: why that request was worth making.

Wording of the requests stays close to the original asks. Hosting logins are left out.

The tool this describes is the table room at the QDNL matchmaking on 26 November 2026.

## Principles

**Know where you are.** The first look tells you the place and the first thing to do.

**One path.** You move through a known sequence, and you can see how far along that sequence you are.

**Short words.** A title, an arrow, or the picture already says it, so the sentence can go.

**Look like the room.** Tables, chairs, and names should be recognisable as the event you walked into.

**The picture tells the truth.** The drawing shows who is actually there, and it stays the drawing you supplied.

**Each seat is one role.** Left to right has a fixed meaning, and the challenge owner is a chair.

**Touch the thing.** The card, the chair, or the icon is the control.

**Stay where you are.** The page holds still, and the next action stays on the screen.

**Keep it all in view.** A name, a decision, or a row of people stays fully visible.

**Feel like QDNL.** The logo, the type, and the blue are the organisation's.

**Say what it is.** A label carries the real weight of the thing: a menu is a menu, an example is a conversation starter.

**One room for everyone.** Whoever opens the site is looking at the same tables.

## 1. Know where to start

The first screen was overwhelming. It was unclear where to look, where to start, or how the parts connected.

- Begin on the table room, and make it obvious that this is a room of tables.  
  **Know where you are.** The first screen is the room, so there is a place to stand.
- Replace the long room introduction with the title only: Table room.  
  **Short words.** The title is the introduction.
- From that room, make it easy to start something new.  
  **Know where you are.** Starting a table is the action the room is for, so it sits in that room.
- Show how many steps a new table has, and what opens next, so navigation is not a surprise.  
  **One path.** You can see how many steps there are, and which one opens next.
- Use words sparingly. Back is a back arrow. Next is a forward arrow.  
  **Short words.** A direction is an arrow.
- The header carries the event: Matchmaking · 26 November 2026. The extra eyebrow line goes away.  
  **Short words.** The event name in the header is enough to place you.

## 2. Look like QDNL

The tool should feel like QDNL, and be easier to scan.

- Use the real QDNL logo, including as the favicon.  
  **Feel like QDNL.** The mark on the page and in the tab is the organisation you are already in.
- Use the QDNL typeface for headings and for the main text.  
  **Feel like QDNL.** Headings and body text are the same voice.
- Prompts are Quantum Delta blue.  
  **Feel like QDNL.** A prompt is the organisation's blue, so it reads as a prompt.
- Black and white stay the base. The add-table button inverts the furniture to white.  
  **Feel like QDNL.** The add button is a black block, so the furniture on it is white.
- The challenge-owner chair is the same blue, on the table picture only. On the black add button, every chair and the table are white.  
  **Feel like QDNL.** Blue is reserved for the challenge owner on the table. On the black button the whole table is white, so the mark stays one colour.

## 3. A room that looks like tables

Opening the tool should feel like walking into a room of tables: organised, and recognisable as a restaurant floor rather than a list of cards.

- Five tables in a row on a wide screen. Two on a narrow one.  
  **Look like the room.** A wide floor of tables reads as a room you can scan.
- A finished table is drawn as a table with the people who are actually there. Chairs, or the table, can be missing.  
  **The picture tells the truth.** A chair appears when that person is here.
- If nobody is marked here, the picture is just the table.  
  **The picture tells the truth.** With nobody seated, the furniture is the table.
- Tables have a name only. No table number.  
  **Say what it is.** The room knows a table by its name.
- A table with no name is called Untitled.  
  **Say what it is.** A table with no name yet still has a name you can read.
- The name is the first thing you can set, at the top.  
  **Know where you are.** The name is how the room will recognise the table, so it comes first.
- Started tables that are not published yet sit on the floor with the others, marked In progress. A list of “Continue” links under the title gets in the way.  
  **Stay where you are.** A table you started is still a table on the floor, so you continue it there.
- Clicking a table blurs the rest of the room and shows that table.  
  **Stay where you are.** Opening a table keeps you in the room. The other tables recede.
- Close is an X, not the word Close.  
  **Short words.** Close is the mark for close.

## 4. Adding, exporting, deleting

The controls in the room should be icons of one height, not sentences.

- New table is a plus together with a full table, built from the separate chair and table icons, all in white.  
  **Touch the thing.** The button is the table you are about to add.
- The add button is large enough to see.  
  **Keep it all in view.** The table on the button is large enough to recognise.
- Export, next to the trash, is a downward arrow.  
  **Short words.** Export is the arrow that means down, beside the other icons.
- On the finished table menu, export is that same downward arrow, and copy is a clipboard icon. Copy has to put the card on the clipboard.  
  **Touch the thing.** The clipboard icon has to put the card on the clipboard.
- Delete is a red trash icon. Removed tables go to a bin that can be emptied.  
  **Touch the thing.** Delete looks like throwing the table away, and the bin can still be emptied.
- Import and print are not part of the tool.  
  **Say what it is.** The event is the room.
- The room does not list which roles every pursuing table is still missing.  
  **The picture tells the truth.** The chairs already show who is missing.

## 5. Fill a table like a form

Creating a table opens its own view, like a form, and only then is it published to the room.

- People move forward one step at a time. They do not skip ahead.  
  **One path.** Each step waits until the one before it is filled.
- The first screen asks only for the name.  
  **Know where you are.** The table starts as a name.
- A progress bar fills gradually when you go forward or back, rather than jumping.  
  **One path.** The bar fills as you move, so the step change is visible.
- The step counter line at the top of the form (“New table, 2 of 5”) comes off. The step row sits up with the line.  
  **Stay where you are.** The steps sit on the line you are already reading.
- Back and onward sit in a bar that stays on screen, on the bottom right, even on a short step.  
  **Stay where you are.** Back and onward stay on screen, including on a short step.
- Choosing Pursue, Keep watching, or Not for quantum does not jump the page.  
  **Stay where you are.** Choosing a decision leaves you at the place you clicked.
- Closing lines at the end of a step (“Next, you ask…”) and the grey rule above them come off.  
  **Short words.** The path already leads to the next step.
- Domain buttons do not carry extra descriptions.  
  **Short words.** The domain name is the button.
- “Add who carries it, and why today falls short” stays folded. It is optional detail.  
  **One path.** Optional detail stays folded, so it does not become another required step.
- The four value lines are statements you click on and off, under “Where can quantum help?”  
  **Touch the thing.** A statement is something you can agree with by clicking it.
- The decision step opens on the three choices.  
  **Short words.** The step is the choice.
- There is no 25-minute clock.  
  **Say what it is.** A clock would make the table look like a timed exercise.
- The kept card is titled “Your table menu.”  
  **Say what it is.** The screen is the menu for that table.
- Prompt examples from the 2023 EQTA are labelled “These are conversation starters.”  
  **Say what it is.** An example from 2023 is a way into the conversation.

## 6. Decisions on one line

Pursue, Keep watching, and Not for quantum sit on one line, on the decision step and on the finished menu.

- The three decisions sit on one line.  
  **Keep it all in view.** The three choices are one comparison, so they share a line.
- The action word is aligned to the top of each button, so Pursue lines up with Keep watching even when a label wraps.  
  **Keep it all in view.** The action words share a top edge, so you can compare them when a label wraps.

## 7. Who is at the table

“What is needed to make it a reality?” becomes “Who is at the table?”

- The instruction under the heading comes off, and so does the black line. There is space before the buttons.  
  **Short words.** The question is the step.
- Every participant is a button, and the buttons fit on one row.  
  **Keep it all in view.** The people at one table are one row.
- The descriptions inside those buttons come off.  
  **Short words.** The role name is the button.
- The labels are Challenge owner, Domain expert, Quantum expert, and Innovation & commerce expert.  
  **Each seat is one role.** The four names are the four seats.
- Societal, legal or ethical is not a button and not a chair.  
  **Each seat is one role.** The chairs match the roles the table actually uses.
- Here and Still looking are not two buttons. The card is the person.  
  **Touch the thing.** Presence is the card itself.
- Clicking a person’s card turns it, and the name and organisation are written on the back.  
  **Touch the thing.** The person is the card. Turning it is how you write their name.
- When the card is not turned, the role is in capitals.  
  **Look like the room.** The front of the card reads as a place card.
- The card grows so the name and organisation are fully visible.  
  **Keep it all in view.** The card grows until the name and organisation are on it.
- The picture of the table and chairs builds under these buttons, and only the people marked here appear.  
  **The picture tells the truth.** Marking someone here adds their seat under the buttons.

## 8. The picture of the table

The picture is a standing view of people at the table. It uses the supplied drawing.

- The view is as if you were photographing the people at the table, standing in front of it.  
  **Look like the room.** You see the table the way you would if you walked up to it.
- Use the supplied image.  
  **The picture tells the truth.** The chairs are the drawing you supplied.
- One leg, the centre pedestal from the original drawing.  
  **The picture tells the truth.** The table keeps the single pedestal from that drawing.
- Front chairs and back chairs come from the supplied SVGs.  
  **The picture tells the truth.** The chairs come from the SVGs you added.
- Back chairs sit high enough that their backrests continue the arc of the front chairs’ backrests.  
  **Look like the room.** The backrests continue one curve, so the chairs belong to one view.
- Chairs sit with the table, at a size that belongs to it.  
  **Look like the room.** The chairs belong to the table, close to it.
- From left to right the chairs are: challenge owner, domain expert, quantum expert, innovation and commerce expert.  
  **Each seat is one role.** Left to right is fixed.
- The challenge owner is the leftmost chair, in QDNL blue.  
  **Each seat is one role.** The owner is the leftmost chair, in the same blue as a prompt.
- In the room, each table shows only the people who are actually there.  
  **The picture tells the truth.** The floor uses the same rule as the form: a seat is drawn when that person is here.

## 9. One shared room

The tables are the room, whichever window you open.

- The same tables are saved on the host.  
  **One room for everyone.** The tables live with the site, in one place.
- Anyone who opens the site sees that shared set, including an incognito window.  
  **One room for everyone.** Another window, including a private one, opens the same room.
- A change in one browser is written back, so the next person sees it.  
  **One room for everyone.** A change is written back, so the next person sees it.
